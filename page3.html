Web do's and dont's

5 Do's of Web Design

  • Do write semantic HTML: Use proper tags like <header>, <nav>, and <main> for better accessibility and SEO.
  • Do practice mobile-first design: Ensure your layout looks great and functions smoothly on smartphones and tablets.
  • Do use external CSS files: Keep your styling separate from your structure so your code stays clean and easy to maintain.
  • Do use clear visual hierarchy: Use proper heading sizes (<h1> to <h6>) and good contrast to guide the reader's eye.
  • Do optimize images and media: Compress files to ensure fast page loading times for every visitor.

5 Don'ts of Web Design

  • Don't use inline styles: Avoid cramming style="..." attributes directly into your HTML tags.
  • Don't overuse <div> tags: Rely on meaningful HTML5 elements instead of stacking endless generic containers.
  • Don't use tables for layout: Use CSS Flexbox or Grid for page positioning instead of old-school HTML tables.
  • Don't make text hard to read: Avoid tiny fonts, low contrast, or long blocks of continuous text without spacing.
  • Don't auto-play media with sound: Never shock users with loud videos or audio that starts playing the moment the page opens.
